# Drowsiness Detection System

## Aim
To detect drowsiness using eye movement.

## Description
This project uses Python, OpenCV, and Mediapipe to monitor eye activity through a webcam. 
If the eyes remain closed for a certain time, an alert sound is triggered.

## Technologies Used
- Python
- OpenCV
- Mediapipe
- NumPy

## Working
The system captures video using a webcam and detects facial landmarks. 
Eye Aspect Ratio (EAR) is calculated to determine whether eyes are open or closed. 
If EAR falls below a threshold, the system alerts the user.

## Output
Face detection with eye tracking and alert system.

## Conclusion
This system helps in preventing accidents by detecting drowsiness early.
